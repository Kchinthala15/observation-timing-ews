# Early-warning statistics under escalating observation density: Code, protocols, and reproducibility materials (version 3.1.0)

This archive accompanies the manuscript

> Chinthala LK. *Early-warning statistics under escalating observation density: a simulation study with evidence from hospital laboratory data.* Manuscript, 2026.

It contains the simulation protocol and code (A1), the MIMIC-IV analysis script (M1) with its aggregate outputs, and the scripts that take every reported number directly from the frozen output files.

**No real patient data are included**, from MIMIC-IV or any other source. MIMIC-IV is available only to credentialed users through PhysioNet under its data use agreement; the MIMIC-IV folder contains code and aggregate results only, with patient counts below 10 suppressed. The simulation outputs do include synthetic patient-level rows (one row per simulated patient, arm, analysis and test); these are generated by the simulation code and describe no real person.

## Reproducing the results

Software used for the reported runs: Python 3.13.14, NumPy 2.5.1, SciPy 1.18.0 (simulation); pandas 3.0.5 (MIMIC-IV). See `requirements.txt`.

**Simulation summary (from the included outputs).** From `a1_simulation/rebuild_v322/`:

```
python -m a1_summary.summarize
```

This recomputes every A1 estimate, interval, calibration label and classification from the patient-level output rows, after checking the configuration hashes and every block's completion record. Run on a second computer from this archive, it reproduced the frozen summary exactly, apart from the last digits of some Clopper–Pearson interval endpoints that depend on the SciPy version.

**Simulation unit tests.** From `a1_simulation/rebuild_v322/`: `python -m pytest tests` (118 tests).

**MIMIC-IV analysis** (requires credentialed access to MIMIC-IV v3.1; place `transfers.csv.gz` and `labevents.csv.gz` from the `hosp` module in one folder):

```
python m1_mimic/code/mimic_specimen_analysis.py --selftest
python m1_mimic/code/mimic_specimen_analysis.py --hosp <folder> --out M1_results
```

The script writes aggregates only. The open MIMIC-IV demonstration dataset can be used with `--demo`.

**Reported numbers, figures and supporting information.** From `reporting/`: `python registry.py` writes every reported number to `registry.json` (rounding: exact stored decimal value, half away from zero). From `reporting/figures/`: `python make_figs.py` draws Figures 1–3 and S1. From `reporting/si/`, with `Figure_S1.png` copied into that folder: `python build_s2.py`, `python build_s3.py`, `python build_s5.py`, and `python build_s4.py <summary>` where `<summary>` is a summary produced by rerunning the summariser.

## Notes

- The MIMIC-IV first-run outputs are included because the manuscript discloses that implementation defects found in that run were corrected before the final analysis. The final analysis is version 1.2.2.
- One planned deviation is recorded in `outputs_addendum_A1/deviations.json` (continuous-time false-alarm block run at 1,000 rather than 2,000 patients).
- The fold-model pilot found no setting meeting the pre-specified rule, so the main fold run was not performed, as the protocol required.
